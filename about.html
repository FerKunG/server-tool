A small project for people who run servers.

FerNode is a Windows desktop app and a small plugin library for Minecraft servers. It is built and maintained by FerKunGsXD as an independent project, not a company or a hosting platform.

What FerNode is

The app collects the routine parts of running a server: starting and stopping a server, watching CPU and memory, taking backups and installing Modrinth add-ons. The goal is not to replace a control panel or a hosting service. It is to make a server on your own PC easier to run without hiding what is happening underneath.

The plugin library is deliberately small. UltraTreeFeller, AutoRefill and FerKunG Stacker each do one job, ship with documented defaults and work as standalone JARs. You do not need the FerNode app to use them, and you can install them on any compatible Paper or Spigot server.

Who builds it

FerNode is developed by FerKunGsXD. Releases, source code and issue tracking live on the FerKunG/server-tool GitHub repository. Video demos and project updates are posted on the FerKunGsXD YouTube channel.

The app is tested on Windows 10 and 11. The plugins target Java 17+ and the Minecraft versions listed on the plugin cards. If a build does not match your server version, it is better to wait for a compatible release than to force it to load.

How the project is funded

The app and plugins are free to download. This website shows advertising through Google AdSense to cover the cost of keeping the site and downloads online. Advertising is separate from the downloads: you can use the app and plugins without creating an account, and the desktop app does not require you to visit the site.

The site does not sell personal information. The privacy policy explains what the hosting provider and Google may collect, and how to control personalised advertising.

Support and bug reports

For a bug in the app or a plugin, open an issue on GitHub with your server version, Java version and the first relevant error from logs/latest.log. The troubleshooting guide covers the problems that come up most often.

For privacy questions or anything that does not fit an issue, contact through the YouTube channel. Please do not send account passwords, hosting credentials or other secrets.
