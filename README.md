# Server Tool website

Public download site for **Server Tool** by **FerKunGsXD**.

- Site: https://ferkung.github.io/server-tool/
- Downloads: [GitHub Releases](https://github.com/FerKunG/server-tool/releases)
- Privacy policy: https://ferkung.github.io/server-tool/privacy.html

The site is plain HTML, CSS and vanilla JavaScript. The application source code is kept
separately and is not part of this repository.

Large downloads are hosted as GitHub Release assets because GitHub Pages rejects files
over 100 MB.
