FerNode plugin bundle
=====================

Includes:
- AutoRefill 1.1.0
- FerKunGStacker 1.3.0
- UltraTreeFeller 1.1.0

Install
-------
1. Stop the Minecraft server.
2. Drop the JAR files into the server's plugins folder.
3. Delete any older copies of the same plugins.
4. Start the server again.

Compatibility
-------------
- AutoRefill 1.1.0: Paper/Spigot 1.21.x, Java 17+
- FerKunGStacker 1.3.0: Paper/Spigot 1.20.x and 1.21.x, Java 17+
- UltraTreeFeller 1.1.0: Paper/Spigot 1.21.x, Java 17+

Always make a backup before changing server plugins.
